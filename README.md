# kutcodelabs.com

The KutCode Labs website: the studio's home page, the MotionArea product page (`/motionarea/`) and its privacy
policy (linked from the Google Play listing as `https://kutcodelabs.com/motionarea/privacy/`). Plain static files —
HTML, one stylesheet, two small scripts and images — in Turkish and English (`lang.js` shows one; `site.js` runs
the moving parts: the header, the picture slideshows and things easing in as they scroll into view).
Served by GitHub Pages; the custom domain is in `CNAME`.
