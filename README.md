# kutcodelabs.com

The KutCode Labs website: the MotionArea home page and its privacy policy (linked from the Google Play listing
as `https://kutcodelabs.com/motionarea/privacy/`). Plain static files — HTML, one stylesheet, two small scripts
and images — in Turkish and English (`lang.js` shows one; `slides.js` cycles the home page's pictures).
Served by GitHub Pages; the custom domain is in `CNAME`.
